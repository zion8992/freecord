# Contributing to Freecord

## List

There are so many things you can do for Freecord. Here is a list of things that we need to be done:

**Logo**<br>
Freecord needs some kind of logo. The [current logo](/static/img/logo.png) is just a placeholder.<br>

**Matrix Instance Moderation**<br>
We need a few moderators to moderate our [matrix instance](/links/chat.md).<br>

**Go Developer**<br>
We are looking with a developer with some experience in working with [Go](https://go.dev).

**Community Member**<br>
Become a community member! You can join the matrix chat instance [here](/links/chat).

## How to get involved

**1. Join the matrix instance**
You can find the join link [here](/links/chat).

**2. Ask**
There are not many users on the matrix instance. Your message should be read withing 48 hours.
